# L

### Native Windows Endpoint Monitoring
L is a C++ project focused on exam-integrity monitoring, and explainable
real-time detection on Windows.

## Goals

- Monitor running processes and relevant process metadata.
- Observe window metadata and foreground application changes.
- Collect network connection metadata.
- Correlate telemetry using deterministic, explainable rules.
- Display local alerts with supporting evidence.
- Maintain timestamped local event logs.
- Evaluate capture-exclusion behavior in a controlled test environment.

## Technology Stack

- C++20
- Windows APIs
- MinGW-w64 / GNU Make
- Git
